# New API on Railway

Readable source of the start script used by the New API Railway template.
The template runs the official image `calciumion/new-api` (pinned by digest) with this script inlined
as base64 in the service start command, so no custom image is built.

## What `start.sh` does

1. Sets a few defaults (`ERROR_LOG_ENABLED`, `BATCH_UPDATE_ENABLED`, `TZ=UTC`).
2. Starts New API on a private port (3999) that Railway's public domain doesn't route to,
   retrying until Postgres is ready.
3. If the instance has never been set up, completes setup itself: it creates the admin account from
   `ADMIN_USERNAME` (default `admin`) and `ADMIN_PASSWORD` (generated by the template),
   turns on self-use mode (`NEW_API_SELF_USE_MODE`, default `true`) and turns off public sign-up.
   Because the public port isn't open yet, nobody can claim the `/setup` page first.
4. Stops the private instance and starts New API on Railway's `PORT`.

On later starts, step 3 is skipped, so changes you make in the admin UI (password, sign-up settings) stay as they are.

## Regenerate the start command

```sh
echo "/bin/sh -c \"echo $(base64 -w0 start.sh) | base64 -d > /tmp/start.sh && exec sh /tmp/start.sh\""
```
